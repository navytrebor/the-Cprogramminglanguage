## Register Variables

A `register`declaration advises the compiler that the variable in question will be heavily used. The idea is that `register` variables are to be placed in machine registers, which may reduce in smaller faster programs. But compiler are free to ignore the advice.

The `register` declaration looks like this:

```c
register int x;
register char c;
```
The `register`declaration can only be applied to automatic variables and to the formal parameters of a function, as in:
```c
f(register unsigned m, register long n)
{
    register int i;
    ...
}
```
Only a few variables in each function may be kept in registers, and only certain types are allowed.
